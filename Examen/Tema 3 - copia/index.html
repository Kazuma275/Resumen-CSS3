Capítulo 3: Selectores en CSS

3.1.1 Selector de Hijos

Los selectores de hijos seleccionan elementos que son hijos directos de un elemento específico.

/* Ejemplo de selector de hijos */

div > p {

color: blue;

}

3.2 Pseudo-clases

Las pseudo-clases se utilizan para definir el estado de un elemento (por ejemplo, cuando se pasa el ratón por encima).

/* Ejemplo de pseudo-clase */

a:hover {

color: red;

}

/* Cambia el color del enlace al pasar el ratón */

p:first-child {

font-weight: bold;

}

/* Selecciona el primer

dentro de un contenedor */

3.3 Pseudo-elementos

Los pseudo-elementos permiten seleccionar y estilizar partes específicas de un elemento.

/* Ejemplo de pseudo-elemento */

p::before {

content: '>>';

color: green;

}

/* Agrega contenido antes de cada

*/

p::after {

content: '<<';

color: green;

}

/* Agrega contenido después de cada

*/

3.4 Agrupación de Selectores

Se pueden agrupar selectores para aplicar el mismo estilo a varios elementos a la vez, optimizando así el código.

/* Ejemplo de agrupación de selectores */

h1, h2, h3 {

margin-bottom: 15px;

}

,

y

p, span, a {
