Ejemplos Avanzados de Animaciones en CSS

Inicio

1. Animación de rebote

Una animación que simula un rebote usando translateY().

/* Animación de rebote */

.bouncing-box {

animation: bounce 1s cubic-bezier(0.25, 1, 0.5, 1) infinite;

}

@keyframes bounce {

0%, 100% { transform: translateY(0); }

50% { transform: translateY(-30px); }

}

2. Animación de deslizamiento lateral

Una animación que mueve un elemento de izquierda a derecha.

/* Animación de deslizamiento lateral */

.sliding-box {

animation: slide 2s ease-in-out infinite;

}

@keyframes slide {

0% { transform: translateX(0); }

50% { transform: translateX(150px); }

100% { transform: translateX(0); }

}

3. Animación de escala

Una animación que cambia el tamaño de un elemento.

/* Animación de escala */

.scaling-box {

animation: scale 1.5s ease-in-out infinite alternate;

}

@keyframes scale {

0% { transform: scale(1); }

100% { transform: scale(1.5); }

}

4. Animación de giro y escalado combinado

Una animación que combina rotación y escalado.

/* Animación de giro y escalado */

.rotating-scaling-box {

animation: rotateScale 3s linear infinite;

}

@keyframes rotateScale {

0% { transform: rotate(0deg) scale(1); }

50% { transform: rotate(180deg) scale(1.2); }

100% { transform: rotate(360deg) scale(1); }

}

5. Animación de cambio de color

Una animación que cambia el color de fondo de un elemento.

/* Animación de cambio de color */

.color-changing-box {

animation: colorChange 2s linear infinite;

}

@keyframes colorChange {

0% { background-color: #2ecc71; }

50% { background-color: #e74c3c; }

100% { background-color: #2ecc71; }

}

6. Animación de opacidad y movimiento

Una animación que cambia la opacidad y la posición de un elemento.

/* Animación de opacidad y movimiento */

.fading-moving-box {

animation: fadeMove 2s ease-in-out infinite;

}

@keyframes fadeMove {

0% { opacity: 1; transform: translateY(0); }

50% { opacity: 0.5; transform: translateY(-20px); }

100% { opacity: 1; transform: translateY(0); }

}

7. Animación de rotación con retraso

Una animación de rotación que realiza giros completos.

/* Animación de rotación con retraso */

.delayed-rotation-box {

animation: delayedRotate 4s linear infinite;

}

@keyframes delayedRotate {

0% { transform: rotate(0deg); }

25% { transform: rotate(90deg); }

50% { transform: rotate(180deg); }

75% { transform: rotate(270deg); }

100% { transform: rotate(360deg); }

}

8. Animación de trayectorias complejas

Una animación que mueve un elemento en un camino específico.

/* Animación de trayectorias complejas */

.path-animation-box {

animation: pathAnimation 5s linear infinite;

}

@keyframes pathAnimation {

0% { top: 0; left: 0; }

25% { top: 0; left: 150px; }

50% { top: 150px; left: 150px; }

75% { top: 150px; left: 0; }

100% { top: 0; left: 0; }

}
