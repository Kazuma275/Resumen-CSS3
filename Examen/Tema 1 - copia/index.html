Técnicas Imprescindibles de CSS

1.1 Propiedades Shorthand

Las propiedades shorthand permiten escribir varias propiedades de manera abreviada para simplificar el código.

/* Ejemplo de margin shorthand */

margin: 10px 20px 15px 5px;

/* Ejemplo de padding shorthand */

padding: 5px 10px;

1.2 Limpiar Floats

Para evitar que los elementos flotados afecten al layout, se puede usar la propiedad clear o un "clearfix".

/* Clearfix */

.clearfix::after {

content: "";

display: table;

clear: both;

}

1.3 Elementos de la Misma Altura

Usar display: flex o display: grid para hacer que los elementos tengan la misma altura.

/* Ejemplo de flexbox */

.container {

display: flex;

align-items: stretch;

}

1.4 Sombras

Se pueden aplicar sombras a los elementos usando la propiedad box-shadow y text-shadow.

/* Ejemplo de box-shadow */

box-shadow: 5px 5px 15px rgba(0, 0, 0, 0.3);

/* Ejemplo de text-shadow */

text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.5);

1.5 Esquinas Redondeadas

Se pueden redondear las esquinas de un elemento con la propiedad border-radius.

/* Ejemplo de border-radius */

border-radius: 10px;

1.6 Transparencias

Usar la propiedad opacity o valores de color con alfa (rgba) para aplicar transparencia.

/* Ejemplo de opacity */

opacity: 0.5;

/* Ejemplo de color con alfa */

background-color: rgba(255, 0, 0, 0.5);

1.7 Sustitución de Texto

Usar la propiedad font-family para cambiar el tipo de fuente o usar propiedades de reemplazo como ::before y ::after.

/* Ejemplo de ::before */

.text::before {

content: "Nuevo texto ";

}

1.8 Rollovers y Sprites

Usar imágenes de sprites para optimizar el uso de imágenes y cambiar el estado de los elementos con :hover.

/* Ejemplo de uso de sprite */

.button {

background-image: url('sprite.png');

background-position: 0 0;

}

.button:hover {

background-position: -50px 0;

}

1.9 Texto

Usar propiedades como text-align, text-shadow, y unidades como em, rem para estilizar el texto.

/* Ejemplo de text-shadow */

text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);

/* Ejemplo de alineación de texto */

text-align: center;
