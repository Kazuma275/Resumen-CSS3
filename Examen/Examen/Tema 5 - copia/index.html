5.1 Imágenes embebidas

Las imágenes embebidas se pueden incluir en CSS usando la propiedad background-image con la URL de la imagen codificada en base64. Esto ayuda a reducir las solicitudes de red y mejora el rendimiento en algunos casos.

/* Ejemplo de imagen embebida */

div {

width: 200px;

height: 200px;

background-image: url('data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAUA...');

background-size: cover;

}

/* Utiliza la imagen codificada en base64 como fondo */

Este método es útil para pequeños íconos o elementos gráficos que no necesitan ser cargados de manera separada desde el servidor.

5.2 Mapas de imagen

Los mapas de imagen se usan para definir áreas clicables dentro de una imagen. Se crean con la etiqueta <map> y se asocian con la imagen usando el atributo usemap.

/* Ejemplo de mapa de imagen */

<img src="imagen.jpg" usemap="#mapa" alt="Mapa de imagen">

<map name="mapa">

<area shape="rect" coords="34,44,270,350" href="https://ejemplo.com" alt="Área 1">

<area shape="circle" coords="300,100,50" href="https://otroejemplo.com" alt="Área 2">

</map>

/* Crea áreas clicables dentro de la imagen */

El uso de <map> es ideal para crear menús interactivos o áreas de navegación dentro de una imagen.

5.3 Control del Scroll

Se pueden aplicar técnicas de control de desplazamiento en CSS para modificar la apariencia de los elementos al hacer scroll. Por ejemplo, la propiedad scroll-behavior permite definir si el desplazamiento de la página debe ser suave o instantáneo.

/* Ejemplo de scroll-behavior */

html {

scroll-behavior: smooth;

}

/* Aplica desplazamiento suave a toda la página */

El desplazamiento suave puede mejorar la experiencia del usuario al hacer que la navegación a través de diferentes secciones de la página sea más fluida.

5.4 Variables CSS

Las variables CSS permiten almacenar valores reutilizables que se pueden utilizar en todo el documento. Se definen con --nombre-variable y se usan con var().

/* Ejemplo de variables CSS */

:root {

--color-principal: #3498db;

--fuente-principal: 'Arial', sans-serif;

}

body {

background-color: var(--color-principal);

font-family: var(--fuente-principal);

}

/* Usa las variables definidas en el documento */

Las variables CSS son muy útiles para mantener la consistencia en los estilos y facilitar la gestión de cambios de diseño.

5.5 La función calc()

La función calc() permite realizar cálculos dinámicos en las propiedades de CSS, como sumar, restar, multiplicar o dividir valores.

/* Ejemplo de la función calc() */

div {

width: calc(100% - 50px);

height: 200px;

}

/* Calcula el ancho restando 50px al 100% */

Usar calc() es ideal para ajustar dinámicamente tamaños de elementos en función de otros elementos o condiciones de diseño.
