Capítulo 6: Transformación en CSS

Inicio

6.1 Propiedad transform

La propiedad transform se usa para aplicar transformaciones 2D y 3D a un elemento. Se puede usar para rotar, escalar, mover, inclinar y más.

/* Ejemplo de transformación 2D */

.transform-box {

transform: rotate(45deg);

}

/* Aplica una rotación de 45 grados al elemento */

Rotar

6.2 Propiedades 3D

Las transformaciones 3D permiten manipular elementos en tres dimensiones. Propiedades como rotateX(), rotateY(), y rotateZ() se usan para rotar en distintos ejes.

/* Ejemplo de transformación 3D */

.transform-3d {

transform: rotateX(45deg) rotateY(45deg);

transform-style: preserve-3d;

}

/* Aplica una rotación en los ejes X e Y */

3D

6.3 Escalado

La transformación de escalado cambia el tamaño de un elemento. Se usa la función scale().

/* Ejemplo de escalado */

.scale-box {

transform: scale(1.5);

}

/* Aplica un escalado del 150% */

Escalar

6.4 Inclinación

La transformación de inclinación distorsiona un elemento en un ángulo específico. Se utiliza la función skew().

/* Ejemplo de inclinación */

.skew-box {

transform: skew(20deg, 10deg);

}

/* Aplica una inclinación de 20 grados en el eje X y 10 en el eje Y */

Inclinación

6.5 Perspectiva

La perspectiva se usa para crear una sensación de profundidad en transformaciones 3D. Se aplica usando la propiedad perspective en el contenedor.

/* Ejemplo de perspectiva */

.perspective-container {

perspective: 800px;

}

.perspective-example {

transform: rotateY(45deg);

}
