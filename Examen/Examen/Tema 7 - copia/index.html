7.1 ¿Qué es una animación? Tipos de animaciones

Las animaciones permiten aplicar cambios visuales a los elementos de una página web de forma progresiva. Existen dos tipos principales: animaciones clave (keyframes) y transiciones.

Las animaciones clave definen una secuencia de estilos a lo largo de un intervalo de tiempo. Las transiciones permiten que un cambio de estado, como pasar el ratón sobre un elemento, se realice de forma suave.

7.2 Módulo Animations

El módulo de animaciones en CSS se usa para definir animaciones complejas mediante la regla @keyframes.

/* Ejemplo de animación de desvanecimiento */

@keyframes fadeIn {

0% { opacity: 0; }

100% { opacity: 1; }

}

.fade-in {

animation: fadeIn 2s ease-in;

}

7.3 Módulo Transition

El módulo de transición permite definir cambios de estilo que se realizan suavemente al cambiar de estado, como al pasar el cursor sobre un elemento.

/* Ejemplo de transición de color de fondo */

.transition-color {

background-color: #3498db;

transition: background-color 0.5s ease-in-out;

}

.transition-color:hover {

background-color: #e74c3c;

}

7.4 Optimizar animaciones

Para mejorar el rendimiento, es importante optimizar las animaciones y transiciones. Algunas recomendaciones incluyen:

  • Usar propiedades que se pueden animar de manera eficiente, como transform y opacity.
  • Evitar animar propiedades de alto costo como width, height y top.
  • Usar la propiedad will-change para indicar qué elementos se van a animar y mejorar la eficiencia del renderizado.

7.5 Trayectorias Animadas

Las trayectorias animadas permiten que un elemento siga un camino específico usando la propiedad motion-path. Este ejemplo muestra un círculo que se mueve a lo largo de una curva definida por un path de Bezier.

/* Ejemplo de animación de trayectoria */

.path-animation-container {

position: relative;

height: 300px;

background-color: #f0f0f0;

border: 2px dashed #ddd;

}

.path-animation {

width: 30px;

height: 30px;

background-color: #3498db;

border-radius: 50%;

position: absolute;

animation: moveAlongPath 4s linear infinite;

motion-path: path('M10 80 C 40 10, 65 10, 95 80');

}

@keyframes moveAlongPath {

0% {

offset-distance: 0%;

}

100% {

offset-distance: 100%;

}

}

7.6 Animaciones al hacer scroll

Las animaciones activadas por el desplazamiento permiten que los elementos se animen a medida que se hace scroll en la página. Esto se puede lograr con combinaciones de transiciones y scripts.

/* Ejemplo de animación al hacer scroll */

.scroll-box {

opacity: 0;

transform: translateY(50px);

transition: opacity 0.3s ease, transform 0.3s ease;

}

.scroll-container:hover .scroll-box {

opacity: 1;

transform: translateY(0);

}
