Capítulo 4: Control del Espacio en CSS

4.1 Propiedad white-space

La propiedad `white-space` controla cómo se gestionan los espacios en blanco dentro de un elemento. Se puede usar para evitar el ajuste de línea, preservar los espacios o manejar el contenido de forma especial.

/* Ejemplo de white-space */

p.no-wrap {

white-space: nowrap;

}

/* El contenido de este

no se ajustará en varias líneas */

4.2 Propiedad display

La propiedad `display` controla el tipo de visualización de un elemento. Se puede usar para convertir un elemento en un bloque, en línea o en otros tipos como `grid` o `flex`.

/* Ejemplo de display */

div {

display: block;

}

/* Un

se comporta como un bloque */

span {

display: inline;

}

/* Un se comporta como un elemento en línea */

4.3 Propiedad outline

La propiedad `outline` se utiliza para dibujar un borde alrededor de un elemento sin afectar su tamaño o disposición. A menudo se usa para resaltar elementos de forma accesible.

/* Ejemplo de outline */

button {

outline: 2px solid red;

}

/* Agrega un borde alrededor del botón */

4.4 BOX-SIZING

La propiedad `box-sizing` controla cómo se calculan las dimensiones de un elemento. Con `border-box`, el padding y el borde se incluyen en el tamaño total del elemento.

/* Ejemplo de box-sizing */

div {

box-sizing: border-box;

width: 100px;

padding: 10px;

}

/* El tamaño total será 100px, incluyendo padding y borde */

4.5 Espacio adyacente: La propiedad shape-outside

La propiedad `shape-outside` permite definir una forma alrededor de un elemento de texto para que el texto fluya alrededor de él. Es útil para crear diseños visuales avanzados.

/* Ejemplo de shape-outside */

.imagen {

float: left;

shape-outside: circle(50%);

width: 150px;

height: 150px;

clip-path: circle(50%);

}

/* Crea una imagen circular que rodea el texto */

4.6 Recorte con una forma concreta: La propiedad clip-path

La propiedad `clip-path` permite recortar un elemento con una forma específica, como un círculo, polígono o elipse, creando un efecto visual único.

/* Ejemplo de clip-path */

.cuadro {

clip-path: polygon(50% 0%, 0% 100%, 100% 100%);

width: 200px;

height: 200px;

background-color: lightblue;

}

/* Recorta el elemento en forma de triángulo */
